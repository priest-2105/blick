# Product

## Register

product

## Users

Designers and frontend developers browsing SVG icon libraries and testing simple animation treatments before using an icon in an interface.

## Product Purpose

Blick helps users search, filter, preview, and tune animated icons quickly. Success means a user can find an icon, inspect how it behaves, adjust core animation parameters, and make a confident selection without leaving the workspace.

## Brand Personality

Precise, minimal, graphic. The interface should feel like a focused design utility rather than a marketing site.

## Anti-references

Avoid bright generic SaaS dashboards, decorative cards, soft pastel palettes, heavy shadows, and playful illustration. The requested visual reference is a stark dark grid shell with cream text and one sharp accent.

## Design Principles

Use structure as the visual identity.
Keep controls dense, predictable, and task-first.
Make the selected state unmistakable without flooding the interface with color.
Let icons remain the main visual content.

## Accessibility & Inclusion

Target WCAG AA contrast. Preserve keyboard focus states, legible labels, and reduced-motion-friendly UI transitions.
